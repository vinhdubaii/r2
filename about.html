About R2

A Purpose-Built Windows-Based
Operating System

R2 is a community-driven OS designed with one clear principle: an operating system should serve its purpose, not pretend to serve everyone.

Overview

Windows, Made for You Again

R2 is a personal-use build of Windows, stripped of bloatware and telemetry, built for people who just want a clean, private, and reliable system without the background noise Windows normally carries.

Philosophy

Built by Purpose, Not by Trend

Most modified operating systems attempt to be everything at once: lightweight, gaming-ready, server-capable, secure, and beginner-friendly — often at the cost of clarity and reliability.

R2 takes a different path. It has one clear target: everyday personal use. A defined set of trade-offs, and a responsibility to do exactly what it claims. Nothing more. Nothing less.

You install R2. You get a quieter Windows. We keep it that way.

Design Principles

What R2 Stands For

Clean by Design

Focused on removing noise, not functionality. Core Windows features remain intact unless there is a clear, technical reason to change them.

Stability First

Every stable release prioritizes predictability, long-term reliability, and controlled updates — so your everyday system just keeps working.

Transparency

No hidden scripts. No undocumented changes. No "magic tweaks" without explanation. Users should understand what their system does and why.

Minimal, Not Broken

Minimalism means fewer unnecessary processes, not missing capabilities. The goal is efficiency without sacrificing essential Windows behavior.

Edition

One Build, Built for Everyday Use

Workstation
Windows, without the noise. Every unnecessary background process, tracking service, and pre-installed app is stripped out, while full compatibility and stability stay intact. Available for both x86_64 and ARM devices.
Release Model

R2 Release Model Overview

R2 ships a single build — Workstation — so the release model stays simple: no product branches to choose between, just a steady cadence of updates that keep the system current and stable.

Versioning Standard

Workstation releases follow a straightforward Major/Minor model:

Major Release (e.g. 1.0, 2.0)

Triggered when Microsoft ships a new-generation LTSC platform / Windows kernel. The entire system is rebuilt from the new base.

Minor Release (e.g. 1.0 → 1.1 → 1.2)

Periodic updates on the same current LTSC platform: the latest Cumulative security patches from Microsoft, refreshed custom UI (Start Menu Category UI, Floating Search Bar), minor bug fixes, and upgraded internal tools (Nux ToolBox).

Verification & Update Process

Windows Update Preserved

The system update service is never blocked or removed. Monthly patches from Microsoft install smoothly without causing sign-in screen freezes.

Silent Patch Verification

We test the compatibility of Microsoft patches before bundling them into the next Minor Release ISO.

Deep Ecosystem Integration

Every release ships with its own optimization toolkit and a synchronized interface, ensuring a consistent experience across versions.

Community Project

Built by Enthusiasts, for Enthusiasts

R2 is not a commercial product. It is a community project built by enthusiasts who care deeply about operating systems, performance, and long-term reliability.

Every release exists because someone needed it — and decided to build it properly.

R2 is built on a genuine Microsoft Windows platform. We do not replace Windows. We refine it — without feature stripping, artificial limitations, or aggressive rebranding.

Who It's For

The Right Tool for the Right Job

Everyday users who want a cleaner Windows
People who care about privacy and don't want background tracking
Laptop and ARM device owners who want better battery life
Anyone who wants Windows to feel lighter without losing stability

If you're looking for enterprise deployment tools or server management features, R2 is not for you. If you just want your own Windows to feel lighter and quieter — welcome.
